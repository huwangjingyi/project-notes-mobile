# 项目速记（移动端 PWA）

一个只分析你主动收集消息的手机端项目收集工具。它不读取微信聊天记录，不要求电脑持续登录微信。

## 使用

从手机微信群中复制或分享一条项目消息，打开页面粘贴，然后选择“解析内容”。确认预算、截止时间、交付物和联系人后保存即可。

本地预览：

```bash
cd project-notes-mobile
python3 -m http.server 4173
```

用手机和电脑在同一 Wi-Fi 时，可访问 `http://<电脑局域网-IP>:4173`。生产使用时部署到 HTTPS 静态托管，才能安装为 PWA。

## 数据与提醒边界

- 项目数据保存到当前浏览器的 `localStorage`，不会上传或同步到此仓库。
- “导出项目数据”会下载 JSON 备份；清除浏览器网站数据也会删除本机项目。
- 当前 PWA 支持离线打开，**不支持在关闭浏览器后自行定时推送**。
- 每日自动提醒需要后续部署 HTTPS 服务，并接入 Web Push 订阅和服务端定时任务；不能由纯静态本地网页可靠完成。
